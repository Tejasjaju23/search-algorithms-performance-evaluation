# Results and Analysis

Run:

```bash
python experiments/run_experiments.py
```

The command creates:

- `experiments/results/benchmark_results.csv`
- `experiments/results/summary.csv`
- PNG performance charts under `outputs/plots/`

## How to Analyze

Discuss:

1. Which algorithms expanded fewer nodes.
2. How heuristic information changed search effort.
3. Whether solution costs were equal or different.
4. How local-search success varied across runs.
5. How CSP heuristics reduced search effort.
6. How performance changed as problem size increased.

### Important

All numerical values in the final report should come from the generated experimental files. Do not invent measurements.
